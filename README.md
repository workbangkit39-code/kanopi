# kanopi
Aplikasi web (PWA) teman kerja penyuluh kehutanan. Catat agenda, buat laporan kegiatan berkop surat siap cetak PDF, tandai potensi dan lahan kritis dengan foto bercap lokasi GPS, pantau tanaman, lihat peta dan cuaca, serta hitung kebutuhan RHL. Bisa dipakai offline, data tersimpan di perangkat dan sinkron saat ada sinyal.
